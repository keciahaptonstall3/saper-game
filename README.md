# Сапёр — Telegram-бот + мини-игра

Полный набор: игра-мини-приложение, бот на aiogram 3, общая таблица лидеров,
реферальные ссылки и ежедневные напоминания.

Файлы:

- **`saper_miniapp.html`** — сама игра (Mini App). Выкладывается на https-хостинг.
- **`bot.py`** — бот: кнопки, команды, HTTP-API для рейтинга, напоминания.
- **`db.py`** — хранилище на SQLite (игроки, результаты, рефералы).
- **`requirements.txt`**, **`.env.example`** — зависимости и настройки.

---

## Как это устроено

Два кусочка, которые общаются между собой:

1. **Игра** — статический файл, живёт на GitHub Pages (бесплатно, https).
2. **Бот** — программа на Python. Отвечает в чате И поднимает маленький
   HTTP-сервер: игра шлёт туда результаты, а обратно получает таблицу лидеров.

Игра прекрасно работает и **сама по себе** (очки, уровни, монеты, бонусы — всё
локально). Общий рейтинг, рефералы и напоминания включаются, когда подключён бот.

---

## Что понадобится

- Аккаунт Telegram (для [@BotFather](https://t.me/BotFather)).
- Аккаунт GitHub (бесплатно) — для игры.
- Python 3.10+ — для бота. Для рейтинга 24/7 — бесплатный хостинг вроде Render.

---

## Шаг 1. Токен бота

1. Открой [@BotFather](https://t.me/BotFather), отправь `/newbot`, задай имя и username.
2. Скопируй **токен** вида `123456789:AAE...` — понадобится дальше. Никому не показывай.

---

## Шаг 2. Выложить игру на GitHub Pages

1. [github.com](https://github.com) → **New repository** → имя `saper`, **Public**, создать.
2. **Add file → Upload files** → перетащи `saper_miniapp.html` → **Commit changes**.
3. **Settings → Pages** → *Source*: **Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
4. Через ~1 минуту вверху появится адрес. Полный путь к игре:
   **`https://ТВОЙ-НИК.github.io/saper/saper_miniapp.html`**
   Открой его в браузере — игра должна запуститься.

---

## Шаг 3. Запустить бота

1. Положи `bot.py`, `db.py`, `requirements.txt`, `.env.example` в одну папку.
2. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Скопируй `.env.example` в `.env` и заполни:
   ```
   BOT_TOKEN=123456789:AAE...
   WEBAPP_URL=https://ТВОЙ-НИК.github.io/saper/saper_miniapp.html
   ```
4. Запусти:
   ```bash
   python bot.py
   ```
5. В Telegram нажми у бота **/start** — придёт кнопка «💣 Играть в Сапёр».

На этом этапе уже работают: игра, кнопки, `/invite` (рефералы), `/top`, напоминания.
Осталось включить **общий рейтинг внутри игры** — шаг 4.

---

## Шаг 4. Включить мировой рейтинг

Чтобы игра показывала общий топ и засчитывала очки, ей нужен публичный адрес бота.
Локальный `python bot.py` для этого не годится (браузер до него не достучится) —
залей бота на бесплатный **Render.com** (или Railway):

1. Загрузи `bot.py`, `db.py`, `requirements.txt` в отдельный GitHub-репозиторий.
2. На [render.com](https://render.com) → **New → Web Service** → подключи этот репозиторий.
3. Настройки:
   - **Start Command**: `python bot.py`
   - **Environment**: добавь переменные `BOT_TOKEN` и `WEBAPP_URL` (как в `.env`).
   - Render сам задаст переменную `PORT` — бот её подхватит.
4. После деплоя получишь публичный адрес вида `https://saper-bot.onrender.com`.
5. Открой `saper_miniapp.html`, найди вверху скрипта строку:
   ```js
   const BACKEND_URL = "";
   ```
   впиши туда адрес бота:
   ```js
   const BACKEND_URL = "https://saper-bot.onrender.com";
   ```
6. Загрузи обновлённый `saper_miniapp.html` обратно на GitHub Pages (перезапиши файл).

Готово — в «Статистике» появится кнопка **🏆 Мировой рейтинг** с общим топом,
а результаты игроков начнут туда попадать.

> Бесплатный Render может «засыпать» при простое — первый запрос разбудит его за
> несколько секунд. Для игры этого достаточно.

## Команды бота

- `/start` — приветствие и запуск игры (учитывает реферальную ссылку)
- `/play` — открыть игру
- `/top` — таблица лидеров прямо в чате
- `/invite` — личная ссылка-приглашение и счётчик друзей
- `/reminders on|off` — ежедневные напоминания про бонус
- `/help` — как играть

---

## Как работают функции

**🏆 Мировой рейтинг.** После каждой победы и получения ежедневного бонуса игра
отправляет боту твои монеты, уровень и рекорды. Подпись Telegram проверяется на
сервере, так что подделать чужой результат нельзя. Топ — по количеству монет.

**👥 Рефералы.** `/invite` даёт ссылку `t.me/твой_бот?start=ref_ТВОЙID`. Кто
впервые заходит по ней — засчитывается тебе, и тебе приходит уведомление.

**🔔 Напоминания.** Раз в день бот пишет тем, кто давно не заходил, что их ждёт
ежедневный бонус. Любой может отключить командой `/reminders off`.

---

## Частые проблемы

- **Кнопка не открывает игру / белый экран.** `WEBAPP_URL` должен быть на `https://`
  и открываться в браузере. По `http` Telegram Mini App не запускает.
- **Рейтинг пустой или не грузится.** Проверь шаг 4: бот задеплоен на публичный
  https-адрес, и он вписан в `BACKEND_URL` внутри игры. Рейтинг работает только
  внутри Telegram (не в обычном браузере).
- **Бот не отвечает.** Убедись, что процесс запущен без ошибок и токен верный.
  Один токен — один запущенный процесс одновременно.
- **Обновил игру — в Telegram старая версия.** Перезалей файл на GitHub Pages,
  подожди минуту, закрой и снова открой Mini App.

Удачи! 💣
